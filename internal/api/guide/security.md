# 安全边界

## 凭据和权限

- 账号密码使用 bcrypt 哈希。管理 API 接受会话 / JWT / Basic Auth，并校验租户及项目权限；上传、发布、部署和期望状态变更需要项目管理权限。
- Pull Token 用于拉取与 Agent，不能当作管理 Bearer JWT。Agent 心跳支持 X-Express233-Token、Basic Auth 或 JWT；CLI 从环境变量或本机配置读取凭据。
- 真实地址、账号、密码、Token、Cookie、私钥、Webhook 与数据库连接串只通过 Secret、环境变量或受控的未跟踪配置注入，不放入仓库、版本包、命令行参数、VCS 字段、截图或日志。
- SSH 凭据加密保存，主机 API 不回传密码或私钥。应核对主机指纹；连通检查与实际部署均需独立确认目标范围。

## 登录和公开接口

登录失败保护可在系统设置控制；启用时默认 1 分钟窗口内 5 次失败临时封禁来源 IP，默认封禁 10 秒，可由服务端配置调整。关闭交互登录保护不关闭无效 Agent Token 的独立保护。收到 429 / Retry-After 应停止密集重试并检查凭据。

GET /api/agent/guide 和 GET /api/agent/guide/{topic} 是公开静态指南，只返回审核过的脱敏文字，不读取账户、Token、SSH 地址、项目、日志或部署状态。主题限定为 overview、agent、gitea、github、security；不是任意文件读取接口，也没有独立的 /guide/ 页面路由。

## 版本与共享配置

已发布文件、文件标签和 VCS 来源不可修改。需要调整时创建新版本；保留策略可能删除历史包，固定部署版本失效时应明确处理，不允许以“最新”掩盖缺失。

server_id 配置按租户共享，在拉取时应用，并未包含在已发布版本的不可变边界中。回滚旧包前要核对当前配置、启动钩子与目标绑定。不要把敏感连接串放入可公开的指南或版本元数据。

文件标签只是下载选择规则，不是独立的机密访问权限。发布标签选 SSH 目标，文件标签选包内文件；两者不能混为权限控制。包内启动脚本和 post_hook 会在部署节点执行，应按可执行代码审查。

## 部署与日志

控制台 dry_run 只解析目标，不连接 SSH、不传包、不停服，也不能证明 SSH 凭据、健康检查或业务链路正常。真实部署需核对项目、版本、逐个 server_id 和备份策略。自主拉取节点不在本次 SSH 操作内。

Linux safe-deploy.sh 校验 PID 所属实例，发送 SIGTERM 并等待退出；默认超时中止换包，正常发布不启用强杀。Windows runner 当前使用 Stop-Process，超时路径含强制停止；不能假设具有相同的数据 Flush 保证。

Agent error_code 仅允许受限标识符，不上传原始命令输出。SSH 脚本输出可能进入逐服日志，脚本本身也应避免输出凭据；不要把日志自动视作已彻底脱敏。操作日志统一保留 30 天，长期证据需按组织策略另行受控留存。长日志可在弹窗内滚动，关闭查看不会取消后台操作。
